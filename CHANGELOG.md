# Changelog

## Unreleased — Phase 1

- Added pure Dart contracts for results and validation, use cases, paging, retry, clock, IDs, logging and public app configuration. The existing `normalizeLabel` API retains its trimming behavior.
- Added the independently versioned `milesoft_ui` package with Material 3 themes, tokens, controls, dialogs, status views, responsive layout and text attribution.
- Added the showcase catalogue and expanded the existing CI job to verify the UI package and dependency-boundary regressions.

The starter kit targets `v0.2.0` after final acceptance. The workspace packages currently declare `0.1.0` independently. See the [integration and migration notes](README.md#integrate-the-shared-packages).
